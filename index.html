Bienvenue sur la carte interactive des pharmacies de Bagneux

Utilisez les boutons + et - pour zoomer, et survolez les points (version ordinateur) pour voir les informations détaillées. En version mobile, il suffit de toucher les points pour voir les détails.

Le territoire de Bagneux dispose de 11 pharmacies (données d'octobre 2025).

Pour utiliser la carte :
- Zoomez/dézoomez avec les boutons + et -
- Survolez les points pour voir les détails et accéder au site web si disponible.

Carte mise à disposition par la CPTS de Bagneux. Données publiques, mises en forme avec QGIS.
